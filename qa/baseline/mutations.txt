#
# Entries are separated by a line of "===". Each names a file, a test scope,
# and an exact old/new pair. The old text must occur EXACTLY ONCE in the file;
# anything else is refused rather than reported, because a control that edits
# the wrong copy of a repeated line reports a clean result about code it never
# touched.
#
# Most of these correspond to a real defect or a real blind spot found in this
# repo. They are here so the same gap cannot reopen quietly.
